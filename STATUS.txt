EXAMPLE USAGE
═══════════════════════════════════════════════════════════════════════════════

Create a circular orbit and propagate:

    #include <physics/Orbit.hpp>
    
    // Create circular LEO (0° eccentricity)
    Phoenix::Physics::Orbit leo(
        7000000.0,              // semi-major axis (m)
        0.0,                    // eccentricity
        0.0,                    // inclination
        0.0, 0.0, 0.0,         // Ω, ω, ν
        3.986e14,               // μ (gravitational parameter)
        0.0                     // epoch
    );
    
    // Get position at t = 1 hour
    auto pos = leo.getPositionAtTime(3600.0);
    auto period = leo.getPeriod();  // ~5400 seconds (~90 minutes)

Manage simulation:

    #include <world/WorldManager.hpp>
    
    Phoenix::World::WorldManager world;
    
    // Register celestial bodies and vessels
    world.registerCelestialBody(earth);
    world.registerVessel(satellite);
    
    // Run simulation
    world.setTimeWarp(10);  // 10x speed
    for (int i = 0; i < 1000; ++i) {
        world.updateSimulation(1.0);  // +1 second
    }

KEY ALGORITHMS IMPLEMENTED
═══════════════════════════════════════════════════════════════════════════════

1. Kepler Equation Solver (Newton-Raphson)
   M = E - e·sin(E)
   Tolerance: 1e-10 rad, Max iterations: 100

2. Anomaly Conversions
   ν = 2·arctan(√((1+e)/(1-e)) · tan(E/2))

3. Coordinate Transformations
   r_inercial = R_z(Ω) · R_x(i) · R_z(ω) · r_orbital

4. State Vector to Elements (Six-Vector conversion)
   Energy, momentum, eccentricity vector, etc.
